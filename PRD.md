# ALIS beauty — PRD и экстракт проекта (для Claude Code)

> Одностраничный маркетинговый лендинг сети студий эстетики **ALIS** (+ выездной
> бьюти-консьерж) и прототип онлайн-записи. Документ описывает продукт, стек,
> структуру, дизайн-систему и текущие ограничения, чтобы ассистент мог продолжать
> работу без повторного реверс-инжиниринга.

---

## 1. Продукт и бизнес-контекст

- **Бренд:** ALIS beauty — сеть студий эстетики и **beauty-concierge**.
- **Основатель (лицо бренда):** Дайана Тарзян.
- **География:** Новороссийск и регион; выезд по России и за границей.
- **Услуги:** аппаратная и инъекционная косметология, лазерная эпиляция,
  перманентный макияж, брови/ресницы, чистка и уход за лицом, массаж лица,
  макияж и укладки, свадебные образы, выездной бьюти-консьерж.
- **Цель сайта:** заявки (запись/консультация), презентация услуг, портфолио,
  команда, отзывы, продажа подарочных сертификатов, квиз-лид под выезд.
- **Языки:** русский (основной) + английский. Русский — приоритет во всём.

## 3. Структура репозитория

```
src/
  app/

    policy | offer | cookies /page.tsx — юридические страницы

  components/legal/   — обёртка юридических текстов
  components/shop/    — компоненты витрины магазина

  assets/             — изображения и SVG (портреты, фактуры)
  shop/               — фото витрины (care-*, type-*, hero-*, prod-*)
```

## 4. Порядок секций главной (`src/app/page.tsx`)

`Preloader → SmoothScroll → ScrollReveal → Header → Hero → About → Brands
(«Нам доверяют») → Services → HorizontalStory (этапы) → FlipGallery (портфолио)
→ BookingWidget (онлайн-запись) → TeamCarousel (мастера) → Certificates
(подарочный сертификат) → LookShowcaseSection (витрина «Образы/Уход») → Reviews
→ QuizConsult (квиз выездного консьержа) → Faq → Footer`

Плюс глобально: `CustomCursor`, `CookieConsent`.

## 5. Инвентарь компонентов

| Компонент | Назначение |
|-----------|-----------|
| `Header` | Плавающая капсула-шапка: лого, меню (флип-ховер в Burgundy), тумблер RU/EN, CTA «Записаться» |
| `Hero` | Первый экран, лого `ÁLIS` (капитель) + `beauty` (скрипт) |
| `About` | «Обо мне» |
| `Brands` | «Нам доверяют» — бейдж + заголовок с акцентом + бегущая лента лого (пауза на ховере) |
| `Services` | Журнальная сетка услуг-плиток; последняя плитка — CTA «Получить консультацию» с эффектом «круг из-под кнопки» |
| `HorizontalStory` | Этапы работы — горизонтальная прокрутка (sticky, `translate3d` по скроллу), высота 90svh |
| `FlipGallery` | Портфолио: фиксированные 8 плиток (раскладка 4/1/3), переворот фото на ховере, **фильтр по категориям** (меняются только фото) |
| `BookingWidget` | Онлайн-запись: услуга → мастер → дата/время → контакты → успех (шаги, `booking-step`) |
| `TeamCarousel` | Мастера: карточки фото + ховер-блюр «Записаться», имя/роль, список «+ / −» характеристик; авто-прокрутка (2.6s), стрелки |
| `Certificates` | Подарочный сертификат: бордовая плашка, продающий список, широкая кнопка, **вращающаяся 3D-карта** (front/back, 9s), искры/звёздочки, модалка заказа |
| `LookShowcaseSection` / `LookShowcase` | Витрина «Образы / Уход» |
| `Reviews` | Отзывы: вращающееся 3D-кольцо карточек (`ring3d`) |
| `QuizConsult` | Квиз выездного бьюти-консьержа (по мотивам traffic-masters): персона слева с репликой, меняющейся на каждом шаге; прогресс-бар + «ШАГ X ИЗ 6»; 5 вопросов (радио-кружок, кнопка «Следующий вопрос») + контакты |
| `Faq` | Две колонки карточек; активная заливается Burgundy; несколько открыты одновременно |
| `Footer` | Бренд, адрес, контакты, форма (не отправляет) |
| `Preloader` | Заставка с лого |
| `ScrollReveal` | Появление `.r-reveal` при скролле (стаггер) |
| `SmoothScroll` | Плавный скролл |
| `CustomCursor` | Гелевая капля-курсор (goo-фильтр), как на paloma.website |
| `CookieConsent` | Баннер согласия |
| `Booking` / `OnlineBooking` | Полные варианты записи (на главной используется `BookingWidget`) |
| `Team` / `Features` / `Projects` / `ForDesigners` | Наследие/неиспользуемые на главной |

## 6. Дизайн-система

### Цвета (два акцента)
| Роль | HEX | Токен | Где |
|------|-----|-------|-----|
| Burgundy (основной акцент) | `#3B0D1A` | `--wine` | Кнопки, тёмные плашки, активный FAQ, эмфаза заголовков, скроллбар |
| Deep Olive Green (второй акцент) | `#4A4B33` | `--olive` | Эйброу-бейджи, метки, маркеры-галочки, мелкие акценты |
| Ink (тёмная база) | `#17191a` | `--ink` | Текст |
| Cream (светлая база) | `#f4efe6` | `--cream` | Текст на бордовом, поверхности |
| Gold (декор) | `#e7c9a0` | — | Кайма карты сертификата, искры |
| Тёмный текст-графит | `#2a2320` | — | Заголовки на светлом |

Производные бордового: `#54121F` (светлее), `#2A0810` (темнее), `#7C2432/#48101E` (карта сертификата).

### Шрифты (все с кириллицей, кроме отмеченного)
Подключение — `next/font/google` в `layout.tsx`; классы — в `globals.css`.

| Роль | Шрифт | Класс/токен |
|------|-------|-------------|
| Заголовки + весь serif | **Cormorant SC** (капитель) | `.font-display`, токен `--font-serif` = `--font-cinzel` |
| Акцентные слова в заголовках + `beauty` в лого | **Great Vibes** (тонкий скрипт) | `.font-script` (`--font-pinyon`) |
| Тело, меню, кнопки, формы | **Inter** | `--font-sans` / `font-sans` |
| Крупный конденсированный (этапы) | **Oswald** (стенд-ин Thunder) | `.font-thunder` |
| Витрина `/shop` | **Geologica** + **Cormorant Garamond** | `.ff-geo` / `.ff-cormorant` |

> ⚠️ **Ограничение кириллицы.** Ажурные латинские скрипты (Pinyon/Bickham/Allura) и
> Trajan/Cinzel **не содержат кириллицы** — на русском подменяются. Поэтому выбрана
> пара **Cormorant SC + Great Vibes** (обе с кириллицей). «Точь-в-точь» латинский
> логотип возможен только на латинице (`ÁLIS`, `beauty`) — так и сделано.

### Ключевые анимации (`globals.css`)
`r-reveal`/`is-in` (появление при скролле, 1.8s), `marquee` (лента брендов),
`ring3d`/`spin3d` (кольцо отзывов), `cert-rotate`/`certrotate` (карта сертификата, 9s),
`certpop`/`certtwinkle` (искры), `fadeGrid` (фильтр портфолио),
`bookingStep` (шаги записи/квиза). Все уважают `prefers-reduced-motion`.

### Конвенции UI
- Скругления карточек 18–22px, плашек — 32px, пилюль — 999px.
- Эйброу-бейдж: пилюля с точкой, Olive.
- Заголовок секции: капитель Cormorant SC капсом + акцентное слово скриптом Great Vibes.

## 7. Интернационализация

- `LanguageProvider` (`src/lib/i18n.tsx`), `type Lang = "ru" | "en"`, дефолт `ru`,
  сохранение в `localStorage["alis-lang"]`.
- В компонентах: `const { lang } = useLang()` и локальный хелпер
  `const t = (ru, en) => (lang === "en" ? en : ru)` **или** объекты `{ ru, en }`.
- Любой новый видимый текст добавлять сразу на двух языках.

## 8. Онлайн-запись и админка (прототип)

- Модель и стор: `src/lib/booking-store.ts` — `Service`, `Master`, `Booking`,
  `Store`; хранение в `localStorage["alis-booking-v1"]`.
- Витрина записи: `BookingWidget` (главная). Полные варианты: `Booking`, `OnlineBooking`.
- Админка `/admin`: список входящих записей; вход по паролю
  `ADMIN_PASSWORD = "alis"` (прототип, **сменить в проде**), сессия в
  `sessionStorage["alis-admin"]`.
- Планируется перенос прототипа на **Supabase** (сейчас только localStorage).

## 9. Статус форм (важно)

**Ни одна форма пока не отправляет данные никуда.** Везде стоит
`// TODO: реальная отправка (Telegram / e-mail / CRM)`:
`Certificates`, `QuizConsult` (+ ответы квиза), `Footer`, `Booking`.
Телефон в `Footer` — плейсхолдер (`+7 (___) ___-__-__`), не настоящий.

**Когда появится канал приёма заявок** (Telegram-бот / e-mail / CRM) —
подключить отправку во всех формах разом и вписать реальный номер/контакты.

## 12. Рабочие конвенции

- Комментарии в коде — **на русском**, описывают «зачем», в стиле существующих.
- Хардкод цветов — HEX в Tailwind-классах (`bg-[#3B0D1A]`); менять палитру лучше
  через токены `--wine` / `--olive` в `globals.css`.
- Коммиты — на русском, суть изменения; подпись
  `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.
- Всегда двуязычие для видимого текста.
- Перед пушем — успешный `npx next build`.
